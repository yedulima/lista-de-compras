Aplicação web simples para organizar lista de compras. Você adiciona os itens que precisa comprar, marca os que já pegou e remove os que não quer mais.

## Funcionalidades

- Adicionar itens à lista de compras
- Validação de campo vazio ao adicionar um item
- Marcar itens como concluídos, com o texto riscado
- Excluir itens da lista
- Exibir a data e a hora em que cada item foi adicionado
- Mostrar uma mensagem quando a lista está vazia

## Como executar localmente

Requer o [Node.js](https://nodejs.org/) instalado.

```bash
git clone https://github.com/yedulima/lista-de-compras.git
cd lista-de-compras
npm install
npm run dev
```
